# Anmol Raj — Portfolio

A responsive, single-page personal web design portfolio.

## Preview locally

Open `index.html` in your browser, or use VS Code with the Live Server extension.

## Deploy to Vercel

1. Create a GitHub repository named `anmol-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` (plus this README).
3. In Vercel, choose **Add New → Project** and import the repository.
4. Deploy. This is a static site and does not need a build command.

## Before publishing

In `index.html`, replace `YOUR_EMAIL@example.com` in the `mailto:` link with your real professional email. Check all text and links before sharing the portfolio.

Brew & Bean is explicitly labelled as a concept project, not commissioned client work.
